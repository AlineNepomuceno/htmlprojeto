Fundamento do Html

"A transformação digital é a integração de tecnologia digital em todas as áreas de um negócio, mudando fundamentalmente como você opera e entrega valor aos clientes. Também é uma mudança cultural que exige que as organizações desafiem continuamente o status quo, experimentem e se sintam confortáveis com a falha."

HTML é a linguagem de marcação padrão usada para criar e estruturar páginas da web. Ele fornece a estrutura básica de um site, que é aprimorada e modificada por outras tecnologias como CSS (Cascading Style Sheets) e JavaScript.

Mas, como surgiu o HTML?
HTML foi criado por Tim Berners-Lee em 1991 enquanto trabalhava no CERN (Organização Europeia para a Pesquisa Nuclear). Ele desenvolveu o HTML como uma maneira de facilitar a troca de documentos científicos entre pesquisadores por meio da World Wide Web.

E o que é a World Wide Web?
É um sistema de documentos interligados e acessíveis via internet. Conectando clientes e servidores por meio do protocolo HTTP (HyperText Transfer Protocol), assim quando você acessa um site, seu navegador (cliente) envia uma solicitação ao servidor onde o site está hospedado, que então responde enviando os arquivos HTML, CSS e JavaScript necessários para exibir a página em seu navegador.

Estrutura Básica

A estrutura básica de um documento HTML inclui os seguintes elementos principais:

  1. <!DOCTYPE html>: Declara o tipo de documento e a versão do HTML.
  2. <html>: Elemento raiz que envolve todo o conteúdo da página.
  3. <head>: Contém metadados, links para arquivos CSS, scripts JavaScript e o título da página.
  4. <body>: Contém o conteúdo visível da página, como texto, imagens, links e outros elementos.

Principais Tags

Algumas das tags HTML mais comuns incluem:

  • <h1> a <h6>: Cabeçalhos de diferentes níveis.
    Exemplo:

    H1

    H2

    H3

    H4

    H5
    H6
  • <p>: Parágrafos de texto.
  • <a>: Links para outras páginas ou recursos.
  • <img>: Imagens incorporadas na página.
  • <ul> e <ol>: Listas não ordenadas e ordenadas, respectivamente.
  • <div>: Contêiner genérico usado para agrupar elementos e aplicar estilos ou scripts.

Atributos das Tags

Atributos fornecem informações adicionais sobre um elemento HTML. Eles são sempre incluídos na tag de abertura e geralmente vêm em pares nome-valor. Alguns atributos comuns incluem:

  • href: Usado na tag <a> para especificar o URL do link.
  • src: Usado na tag <img> para especificar o caminho da imagem.
  • alt: Fornece um texto alternativo para imagens, útil para acessibilidade.
  • style: Permite aplicar estilos CSS diretamente a um elemento.
  • id: Atribui um identificador único a um elemento, usado para estilização ou manipulação via JavaScript.

Textos

No HTML, o texto pode ser formatado usando várias tags, como:

  • <strong>: Destaca o texto em negrito.
  • <em>: Enfatiza o texto em itálico.
  • <mark>: Destaca o texto com uma cor de fundo.
  • <blockquote>: Define uma citação em bloco.
  • <abbr>: Define uma abreviação ou sigla.

Listas

Existem dois tipos principais de listas em HTML :

  • Listas não ordenadas (<ul>): Usadas para itens que não têm uma ordem específica. Cada item da lista é definido com a tag <li>.
  • Listas ordenadas (<ol>): Usadas para itens que seguem uma sequência numérica ou alfabética. Cada item da lista também é definido com a tag <li>.

Links

Links são criados usando a tag <a> (âncora). O atributo href é usado para especificar o destino do link. Exemplo:

            <a href="https://www.exemplo.com">Visite o Exemplo.com</a>

Estilizações Adicionais no Html

Embora o HTML seja usado principalmente para estruturar o conteúdo, ele também permite algumas estilizações básicas usando atributos como style. No entanto, para estilizações mais avançadas, é recomendável usar CSS. Exemplo de estilização básica em HTML:

            <h1 style="color:blue; text-align:center;">Título Azul Centralizado</h1>
